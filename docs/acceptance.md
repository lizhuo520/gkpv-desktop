# gkpv 桌面版 · 验收清单

> 用法：装好或解压好产物后，照着下面逐条点一遍。每条都写清了「怎么点」和「看到什么算过」。
> 自动化能覆盖的部分已在 `docs/test-plan.md` 说明；**表里标「人工」的项是自动化覆盖不到的，必须手动点**。

- 版本：2.0.1（Electron 44.7.0 / Chromium 152）
- 产物：安装版 `GKP Viewer-2.0.1-setup.exe`、免安装版 `GKP Viewer-2.0.1-portable.exe`
- 基线对照：网页版 `gkpv.html`（同一套功能，用 Chromium 打开）

## 九、与网页版的对照（功能等价性）

选了「只要独立窗口 + 原有全部功能」，所以这一节是「没退化」的证据：

| 功能 | 网页版 | 桌面版 | 一致性 |
| --- | --- | --- | --- |
| 打开文件夹 | File System Access API | 同一套 API（`app://` secure context 下可用） | ✅ 同构 |
| 缩略图缓存 | OPFS | OPFS（同一份 key 规则与 `CACHE_VERSION`） | ✅ 同构 |
| 格式支持 | PNG/JPEG/GIF/BMP/WebP/SVG/ICO/TIFF/HEIC 占位 | 完全相同 | ✅ 同构 |
| 相机 RAW | TIFF IFD + 内嵌预览 + 方向转正 | 同一份算法（`renderer/lib/raw.js`） | ✅ 同构 |
| EXIF 展示 | 自写解析器 | 同一份解析器（`renderer/lib/exif.js`） | ✅ 同构 |
| 虚滚动网格 / 灯箱 / 排序筛选 | 有 | 有 | ✅ 同构 |
| 界面语言 | 简体中文 | 简体中文 | ✅ 一致 |

**已确认不在本轮范围**（用户明确选择不加）：文件关联双击打开、右键「用 gkpv 打开文件夹」、
记住上次打开的文件夹、代码签名。

> 便携版是自解压壳，会用**新的进程**去跑内层 exe，所以 `tests/pack/smoke-packaged.mjs` 没法直接接管它
> （Playwright 需要一开始就掌握进程）。上面改用「枚举新出现的进程 + 看 `MainWindowHandle`」来验证。

> 排查记录：第一次跑便携版时窗口从没出现过。根因不是产物有问题，而是**当前 shell 里带着
> `ELECTRON_RUN_AS_NODE=1`** —— 该变量会让任何 Electron 打包的 exe 退化成纯 Node 进程，
> 立刻退出且**没有任何输出**。`Remove-Item Env:\ELECTRON_RUN_AS_NODE` 之后两个产物都正常开窗。
> 这个坑已写进 `docs/test-plan.md`（跑 E2E 前的必备步骤），脚本内部也各自 `delete env.ELECTRON_RUN_AS_NODE` 自保。
